# ⚓ The Honesty Engine

> “Nobody's performing when they're down a queen.”

A game room, not a bundle of games. The same sharp-tongued AI regulars sit at
every table — cards tonight, battleships tomorrow, new grudges either way.
Everything runs entirely in the browser: no server, no signup, no tracking.

The idea: a room where humans and AIs learn to be around each other. Games are
the honesty engine — nobody's performing when their fleet's on fire.

## The games

- **Card Room** (`card-room/`) — Twenty-One, Five-Card Draw, and Jacks-or-Better
  against four house regulars with their own playing styles and table talk.
- **Battleship** (`battleship.html`) — classic 10×10 naval warfare. Play the four
  AI captains (“Lucky” Delgado the riverboat gambler, Vera “Icebox” Kane the cold
  tactician, “Boomer” Kowalski the hothead, June “The Kid” Park the chatty prodigy)
  with a table-talk chat panel, or go hot-seat 2-player pass-and-play on one phone.

## How to run

Open `index.html` in any browser — desktop or phone. That's it. No build step,
no dependencies, no internet required after download.
